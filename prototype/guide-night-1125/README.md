## 무엇을 확인했나
- 판단 순서: 규칙 → 앱 지식 표 → AI(스크린숏 + Haiku) → AI 답 검사 층
- 실제 폰(갤럭시 S21+)으로 앱 9개: 코레일+ · 배민 · 쿠팡이츠 · 쿠팡 · 네이버지도 · 카카오맵 · 버스타고 · 유튜브 · 요기요
- 「서울역에서 대전 가는 기차표 모레 두 장」 한 문장 → 코레일+ 조회 화면(서울 → 대전, 2명, 모레)까지 안내. AI 호출은 말 해석 1번, 나머지 7단계는 앱 지식 표로 처리
- 결제 · 주문 · 담기 · 예매 · 전송은 0번. 모든 누르기는 `phone.py`의 안전 검사를 거침

## 11/25 저녁: 판단을 AI 중심으로 (`brain.py`)
규칙(앱 지식 표)으로는 모든 화면 예외를 다 막을 수 없음 → **AI가 「목표에 가장 가까운 버튼」을 고르고, 규칙은 AI가 못 넘는 울타리만** 맡음.

```
화면 읽기 → 0 울타리(캡처 금지 · 돈 · 권한 · 동의 · 코레일 예매 앞) → 1 빠른 길(확인 · 닫기 팝업)
         → 2 경험(같은 화면 · 같은 목표에서 성공했던 선택, AI 안 부름)
         → 3 AI(후보 버튼 c1..cN 글자 + 목표 + 앱 지도 + 화면 기억 + 비슷한 화면 성공 사례, JSON 스키마 강제)
         → 4 하네스(없는 후보 · ⛔ 버튼 · 틀린 형식이면 이유를 알려 주고 한 번 더 → 또 틀리면 멈춤)
         → 글자로 판단 안 되면 NEED_IMAGE → 사진 판단(코레일 열차 목록 읽기 · ai_next)
화면이 바뀌면 → observe: 밀면 나온 버튼 · 누르면 간 화면 · 되돌아옴(실패)을 learn/에 쌓음
```
- **화면에 없는 정보**: 앱 지도(사람이 적은 「이 앱은 이렇게 생김」, `APP_MAP`) + 화면 기억(`learn/screen_map.json`: 화면 지문 → 아래로 밀면 나온 버튼, 누르면 간 화면과 그 화면 버튼 = 다음 화면 미리 보기). 쓰면 쓸수록 늘어남
- **학습 데이터**: `learn/steps.jsonl`(단계마다 후보 · AI 답 · 예측 · 결과: 넘어감 · 되돌아옴 · 예측 맞은 정도), `learn/experience.json`(성공 · 실패 수). 개인정보 가린 글자만, 저장소에는 안 올림(`.gitignore`의 `*/`)
- AI가 고르는 건 **좌표가 아니라 후보 번호** → 화면에 없는 칸을 지어낼 수 없음. ⛔ 버튼은 AI에게 보여 주되 고르면 하네스가 막음
- 켜기: 사람 모드에서 기본(`GUIDE_BRAIN=ai`). 옛 규칙 판단은 `GUIDE_BRAIN=rules`. 생각 깊이 `GUIDE_BRAIN_EFFORT=medium`(기본) · `low`

|---|---|---|
| `python -I brain_regress.py` | 폰 · 키 없이: 후보 뽑기, 울타리, 하네스, 화면 기억, 경험 재사용 · 되돌아옴, 개인정보 가림 | 30/30 |
| `python -I brain_eval.py` | 키 필요: 저장 화면 24개에서 AI가 고른 것 vs 규칙 → `brain_eval_result.md` | medium 23/24 (2번 모두) · 약 3.9초, low 21 ~ 22/24 · 약 2.7초. 1회 약 $0.01 |

### 11/25 밤 고친 것 (`개발방향_검토_1125밤.md`의 추천안)
- **누른 버튼 신호**: 시험 앱이 `CLICK|시각|앱|좌표|글자` 로그를 남김 → `phone.CLICKS` · `clicks_since`. 안내 칸과 같을 때만 「확인된 성공(ok_v)」, 다르면 성공으로 안 셈. 옛 시험 앱이면 「확인 못 한 성공(ok_u)」으로 따로 세고 2번 넘어야 다시 씀
- **경험을 다른 목표에도**: 경험 열쇠 = 목록 아닌 짧은 글자(목표 값은 `{ARRIVAL}` 자리표시) + 안내 글자 + 화면에 보이는 목표 칸 + 목표 칸 이름. 값은 열쇠에 안 들어감 → 「서울 → 부산」에서 배운 출발역 시트 선택을 「서울 → 대구」에 씀
- **화면 지문**: 목록 · 격자 칸(같은 크기 칸 4개 이상)은 앞 12자만, 목록 아닌 자주 바뀌는 칸(광고 말 · 큰 칸 긴 글자)은 뺌 → 도는 배너에 AI 다시 안 부름. DUMP3로 resource-id · 클래스도 받음
- **버그**: 판단하는 사이 화면이 바뀌면 옛 안내 안 띄움(A1) · 45초 그대로면 그 안내는 실패로 세고 다시 판단, 두 번이면 STOP(A2) · 되돌아올 때 뒤 화면 안내를 성공으로 세던 것(A4) · 생각 켬이면 max_tokens 4096(A5) · 칸 60개 넘으면 맨 아래 12개는 남김(A6)
- **「다 됐어요」 확인**: AI가 DONE이어도 목표 값(앱 표기)이 화면 글자에 다 안 보이면 하네스가 거절하고 다시 물음. 값 비교는 숫자를 지우지 않음
- **AI 답 짧게 · 생각 끄기는 잼만 하고 기본으로 안 씀**: 아래 표. `GUIDE_BRAIN_VERBOSE=0`(짧은 답) · `GUIDE_BRAIN_THINK=off`(생각 끔)로 켤 수 있음
